# SHAP-LIME-Project

# How to Use the SHAP vs LIME App

1. **Home** – Read what the project does.

2. **Prediction** – Enter the 30 feature values and click **Predict**.

3. **SHAP** – See which features affected the prediction most. Choose Top 5, 10, or 15.

4. **LIME** – See the same type of explanation using LIME.

5. **Comparison** – Compare SHAP and LIME and see how much their important features overlap.

6. **Experiments** – View the project's research experiments and results.

7. **Computational Cost** – Compare how long SHAP and LIME take.

8. **About** – See information about the dataset, model, and methods.

**Simple flow:**
**Prediction → SHAP → LIME → Comparison → Experiments**
